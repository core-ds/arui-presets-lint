Ship a consolidated English lint-standards block into consumers' `AGENTS.md`.
On `postinstall` (and via the manual `arui-presets-lint agents` command) the
package merges an autogenerated, marker-delimited rules block into the project's
`AGENTS.md`, so AI coding agents follow the house ESLint/Stylelint/Prettier
conventions up front. The sync is idempotent, preserves surrounding user content,
skips this repo itself, and can be disabled with the
`ARUI_PRESETS_LINT_SKIP_AGENTS` environment variable.
